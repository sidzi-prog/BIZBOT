# BizBot

A modular business management bot built with Python.

## Overview

BizBot is designed to help businesses manage users,
requests, and administrative operations through a
messaging platform.

## Features

- User management
- Role-based access control
- Request management
- Administrative reports
- Database integration

## Technology Stack

- Python
- SQLite
- Telegram Bot API
- Pytest
- Git
